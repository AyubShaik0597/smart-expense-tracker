# Smart Expense Tracker API

A REST API built using Java 17 and Spring Boot for managing personal expenses. The application stores data in memory and does not require a database.

## Features

- Add an expense
- View all expenses
- Filter expenses by category
- Calculate overall expenses
- Calculate expenses by category
- Delete an expense
- Swagger/OpenAPI documentation

## Requirements

- Java 17+
- Maven 3.8+

## Install

```bash
mvn clean install
